# Code of conduct

Contributors and maintainers should make this project welcoming, constructive, and respectful. Discuss ideas with evidence, accept corrections, credit other people's work, and respect different experience levels and backgrounds.

Harassment, discriminatory language, threats, targeted personal attacks, publishing private information, and unwanted sexual attention are unacceptable. These standards apply in repository issues, pull requests, discussions, reviews, and other project spaces.

Report concerns privately to a repository maintainer through their GitHub profile, asking for a private channel before sharing sensitive details. Maintainers will protect reporter privacy as far as practical, assess reports fairly, and explain actions to the people involved. A report involving one maintainer should be handled by another when available; current maintainer coverage is documented in governance.

Maintainers may edit or remove harmful content, request a behavior change, temporarily restrict participation, or permanently ban repeated or severe misconduct. Enforcement should be proportional, documented privately, and open to a good-faith appeal through an uninvolved maintainer when possible.
