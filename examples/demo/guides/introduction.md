## Welcome to Orbit

Orbit gives you a simple, powerful API for managing projects and connecting your applications. Our REST API is designed to feel familiar, so you can spend less time reading and more time building.

Whether you are prototyping your next idea or running at scale, you are in the right place.

> **A great developer experience, by default.** Every endpoint includes interactive examples, clear schemas, and ready-to-use code in your favorite language.

## Start building

Get from your first request to a working integration in just a few minutes.

1. **Get your API key.** Create a workspace and generate a key for your environment. For the local demo, use `demo-token`.
2. **Make your first request.** Follow the quickstart to list projects with cURL, JavaScript, Python, or Java.
3. **Explore the API.** Browse endpoint references and send real requests from the interactive playground.

## Designed for your workflow

- **RESTful and predictable.** Standard HTTP methods, meaningful status codes, and JSON responses.
- **Secure by design.** Token-based authentication and explicit permissions for every resource.
- **Built to scale.** Cursor-based pagination and consistent resource models.
- **Speak your language.** Copy examples in cURL, JavaScript, TypeScript, Python, and Java.

## Base URL

The included example uses a local mock API. Start it with `npm run demo:api` before sending requests in the playground.

```text
http://127.0.0.1:4010/v1
```

> This is a working demo, not a hosted production API. Connect your own OpenAPI spec to document your service.

## What's next?

Start with the [quickstart](quickstart.md#heading-make-your-first-request), learn how authentication works, or go straight to the API reference. You can try every example directly from your browser.
