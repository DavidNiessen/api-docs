## Choose your runtime

<Tabs>
  <Tab title="JavaScript">
    JavaScript runs this example with the built-in fetch API.

    ```js
    const response = await fetch('https://api.example.com/health');
    console.log(await response.json());
    ```

  </Tab>
  <Tab title="Java">
    Java runs this example with the standard HTTP client.

    ```java
    var client = java.net.http.HttpClient.newHttpClient();
    ```

  </Tab>
</Tabs>
