## Latest completed increment

**Reviewed release plans can now prepare consistent npm, runtime, Java and changelog metadata.** Preparation replays a source-bound plan, requires a clean checkout, stages and audits the complete candidate, and defaults to a read-only receipt of changed paths and hashes. Explicit application updates all owned versions/internal dependency references without resolving third-party dependencies, preserves file modes and changelog history, and leaves the result for Git review. Apply locking, snapshot/source checks and rollback protect against overlapping preparations, failed writes and concurrent edits. Recovery originals are retained when rollback cannot safely replace a concurrent edit. The estimate remains 73% pending the clean-repository command rehearsal; signing/publication and launch acceptance remain separate. See [release preparation](../releases.md#prepare-the-reviewed-metadata).

Validation for this increment:

- The complete local check passed, including 63 tooling tests and all 364 compiler/component tests, version alignment, formatting, ESLint, Markdown lint and TypeScript.
- Temporary repositories exercise read-only staging, full version application, unchanged third-party lock entries, npm-canonical offline lockfile validation from an empty cache, changelog history, stale/altered/dirty plans, symlink refusal, duplicate notes, failure rollback, concurrent edits/commits, overlapping applies and CLI error exit codes.
- Replacements are atomic per file. Process/host interruption still requires inspecting Git changes and the retained apply lock; no filesystem-wide transaction is claimed.
- Reader/browser behavior is unchanged in this increment. The preceding UI increment passed the 25-journey browser suite and two additional response/fallback checks, plus all 12 installed npm components. Those checks were not repeated for metadata-only tooling.

These results do not establish remote CI, registry ownership, signed provenance, installation from published registries or production launch acceptance.
