## Latest completed increment

**Nested JSON objects and homogeneous arrays now have bounded field controls in the request playground.** Referenced and recursive object schemas expand into editable fields. Arrays support adding/removing primitive, object and nested-array items, with a per-container Fields/JSON switch and inherited write-only string masking. Updates retain precise numeric tokens, unknown values, read-only properties and unrelated siblings. Structural array edits discard incomplete drafts before reindexing and restore keyboard focus to a usable control. Invalid drafts block sending until fixed or discarded. Complex schemas and containers beyond the shared 100-control/eight-level budget retain local JSON editors; each expanded array has a 50-item limit. The Scalar-style URL bar and response-only Monaco modal remain covered by browser journeys. This implemented array-editing scope raises the engineering estimate to approximately 75%; root-array/composed controls and production launch acceptance remain pending.

Validation for this increment:

- Formatting/lint, type checking, 65 tooling tests and all 378 compiler/component tests pass.
- All 31 reader browser journeys pass, including real nested object/array requests, exact numeric tokens, draft/error cleanup, focus restoration, both themes, automated accessibility checks and mobile containment.
- All 12 installed npm components pass archive, public API, CLI, adapter and dependency checks outside the workspace, including an offline lockfile reinstall.

## Previous release-preparation increment

The saved-plan round-trip and package-formatting issues found during rehearsal were fixed and tested. A shared CI action handles read-only/application modes; the manual workflow requires `master`, reuses the quality workflow's Java matrix, checks prepared source/server/Studio/Java candidates, and retains unpublished evidence without tags, commits or publication.
