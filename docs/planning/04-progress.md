## Latest completed increment

The explorer SDK now prepares real binary multipart uploads as immutable Blob parts, preserving file bytes, repeated fields and exact JSON number tokens. Sending creates a fresh cryptographic boundary and matching header; preparation remains deterministic. Limits, required-field presence, direct schema references, part content types, header safety and conservative redaction are implemented. Reader upload controls, schema-aware multipart previews and executable multipart snippet generators remain pending. This foundation alone does not raise the overall 72% estimate. See the [multipart SDK reference](../multipart-bodies.md).

Validation for this increment:

- Formatting, ESLint, Markdown lint, TypeScript and all 349 unit/component tests passed, including 25 multipart cases.
- An independent multipart parser and a genuine loopback HTTP server verified binary bytes, Unicode, repeated fields/files, JSON content without filename metadata, exact numeric tokens and valid boundaries.
- All 18 existing browser journeys passed. These are regression checks; no reader upload controls are claimed yet.
- All 40 existing snippets executed successfully across five languages. Multipart requests currently fail explicitly in the snippet generator rather than yielding bodyless examples.
- All 12 packed components installed outside the workspace. The installed SDK encoded and independently parsed binary upload bytes without workspace source resolution.

These results apply to the tested local candidate. They do not establish a complete platform matrix, independent review or installation from published registries.

## External launch dependencies

GitHub Actions has been unable to start because of the repository account's billing or spending limit. Local checks pass, but remote CI has not been verified. Maintainers must resolve that account setting before its checks can serve as release evidence.

Package scope ownership, Maven namespace/signing, registry publication, final product naming and protected repository/environment settings still require owner-controlled setup. No public packages or stable release have been published. External pilots and independent security/accessibility reviews remain required.
