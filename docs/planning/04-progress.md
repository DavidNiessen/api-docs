## Latest completed increment

All five SDK snippet generators now create executable multipart uploads with runtime boundaries, per-part content types and numbered local file placeholders. Selected file bytes and original filenames never enter generated source. cURL uses a private temporary body, Node uses file-backed Blobs, Java uses file body publishers, and Python uses its standard library. Conservative redaction keeps JSON-part placeholders syntactically valid. The reader now sends ordinary requests through the shared fetch adapter. An actual Node fetch header collision found by the harness is handled using a case-equivalent field spelling. Reader upload controls and schema-aware multipart previews remain pending, so the overall estimate remains 72%. See [multipart requests and executable snippets](../multipart-bodies.md).

Validation for this increment:

- Formatting, ESLint, Markdown lint, TypeScript and all 349 unit/component tests passed.
- All 60 generated clients executed across cURL, JavaScript, TypeScript, Python and Java: 40 existing cases and 20 multipart cases. The loopback server independently parsed binary/empty files, repeated fields, NUL/Unicode text, exact numeric tokens, part content types and generic filenames; HTTP failures and redirects produced the expected exits without a second request.
- Raw wire checks verified own `__proto__` headers across all 60 requests; the SDK's real multipart HTTP test verifies the same field. Preparation does not rely on JavaScript object-literal semantics for these headers.
- All 18 existing browser journeys passed after adopting the common fetch adapter. Reader upload controls are not claimed yet.
- All 12 packed components installed outside the workspace. Installed SDK generators resolved their internal multipart module, produced numbered file placeholders and did not include the selected fixture filename.

These results apply to the tested local candidate. They do not establish a complete platform matrix, independent review or installation from published registries.
